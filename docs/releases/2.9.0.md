## Summen A/B als Ziel (#71)

Die Summen haben im DSP kein eigenes Pegelregister. Die Firmware skaliert deshalb ihre Mixer-Koeffizienten (Zeilen
C1/C2, alle Quellen) über dem gespeicherten Mixer; der Mixer selbst bleibt unverändert, gespeichert wird nichts.
Änderungen gehen ohne Stummschaltung in den DSP.

- **GALA** (Typ 110): Sets 4 Bit 0 = Summe A, Bit 1 = Summe B. Die Anhebung kommt wie bei den Ausgängen dazu.
  Typversion jetzt 21 (`modc.version.attributes.ac`), daran erkennt die GUI die Funktion.
- **Volumen-Block** (Typ 16): Flags 2 Bit 0 = Summe A (Absenkung wie die ungeraden Ausgänge, Event 1), Bit 1 =
  Summe B (wie die geraden, Event 2), Bit 2/3 = Korrektur/Balance auch auf diese Summen. Ausschalten oder ein anderer
  Typ setzt die Summen auf 0 dB zurück. Typversion bleibt 20 (Original-GUI).
- Details: `docs/port-changes.md`, Abschnitt GALA.

Vorsicht: Eine Anhebung vor den Ketten 35/36 kann zusammen mit starken EQ-Anhebungen im DSP übersteuern.
